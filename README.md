# HEDGE — Headway Generator
### By Mikrotrans Utara

Aplikasi manajemen dan generator jadwal keberangkatan armada bus/angkot otomatis (Headway Generator) dilengkapi mode papan display/monitor keberangkatan untuk pos dispatch.

## Fitur Utama

- **Main Branding:** HEDGE
- **Sub Branding:** Headway Generator
- **Operator / Pos:** By Mikrotrans Utara
- **Engine Multi-Rute Simultan:** Menghitung interval dan ritase secara dinamis dan presisi.
- **Papan Display / Monitor:** Tampilan real-time countdown keberangkatan armada.
- **Ekspor Lengkap:** Unduh jadwal dalam format Excel (.xlsx), PDF, TXT, gambar PNG, dan salin ke pesan WhatsApp.
- **PWA Ready:** Dapat diinstall di perangkat mobile / desktop dan beroperasi saat offline.

## Cara Menjalankan Secara Lokal

**Prasyarat:** Node.js (LTS disarankan) & pnpm

1. **Install dependensi:**
   ```bash
   pnpm install
   ```

2. **Jalankan aplikasi (Development Server):**
   ```bash
   pnpm run dev
   ```

3. **Akses aplikasi di browser:**
   Buka `http://localhost:3000`
